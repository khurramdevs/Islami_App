#  Islami App

A beautifully designed Islamic companion app built with Flutter,
featuring a modern Dark-Gold aesthetic inspired by Islamic architecture.

##  Features

-  **Surahs** — Browse and read all 114 Surahs of the Holy Quran
-  **Azkar** — Morning & Evening Athkar with a beautiful UI
-  **Hadith** — Explore authentic Hadiths daily
-  **Audios** — Listen to Quran recitations
-  **Elegant Dark-Gold Design** — Inspired by Islamic architecture and aesthetics

##  Built With

- [Flutter](https://flutter.dev/) — Cross-platform mobile framework
- Dart — Programming language

##  Getting Started

1. Clone the repo
   git clone https://github.com/khurramdevs/Islami_App.git

2. Install dependencies
   flutter pub get

3. Run the app
   flutter run
